# 🛡️ Gadget & Warranty Vault

**Gadget & Warranty Vault** คือ Web Application สำหรับจัดการข้อมูลฮาร์ดแวร์ อุปกรณ์ไอที ระยะเวลาประกัน และประวัติการเคลม เพื่อช่วยให้ผู้ใช้สามารถติดตามสถานะของอุปกรณ์ได้อย่างเป็นระบบ ป้องกันปัญหาการลืมวันหมดอายุประกันและเอกสารสูญหาย

## 🎯 ปัญหา (Problem)
ผู้ใช้งานทั่วไป เช่น นักศึกษา, เกมเมอร์, ฟรีแลนซ์ หรือผู้ที่มีอุปกรณ์ไอทีจำนวนมาก มักจะพบปัญหา:
*   จำวันหมดอายุประกันของอุปกรณ์แต่ละชิ้นไม่ได้ ทำให้พลาดสิทธิการเคลมฟรี
*   จำไม่ได้ว่าซื้อจากร้านไหน หรือเอกสารใบเสร็จสูญหาย
*   ไม่สามารถติดตามค่าใช้จ่ายในการซ่อมบำรุงหรืออัปเกรด (เช่น ค่าสวิตช์คีย์บอร์ด, ค่าซ่อมจอ) ได้อย่างเป็นระบบ

## 💡 ทางแก้ (Solution)
*   **ระบบคำนวณวันหมดประกันอัตโนมัติ:** คอยตรวจสอบและแจ้งเตือนเมื่อประกันใกล้หมดอายุ
*   **รวมศูนย์ข้อมูลอุปกรณ์:** จัดเก็บข้อมูลสเปก, วันที่ซื้อ, ร้านค้า และประวัติการเคลมไว้ในที่เดียว
*   **ใช้งานง่ายผ่านเว็บบราวเซอร์:** รองรับการใช้งานบนอุปกรณ์หลากหลาย ไม่ต้องติดตั้งโปรแกรม

## ✨ ฟีเจอร์หลัก (Features)
- [x] **User Authentication:** ระบบสมัครสมาชิก (Register), เข้าสู่ระบบ (Login) และออกจากระบบ (Logout) แบบแยกข้อมูลส่วนบุคคล
- [x] **Asset Management:** ระบบเพิ่ม, ดู และลบข้อมูลอุปกรณ์ไอที (CRUD)
- [x] **Warranty Tracker:** คำนวณวันหมดอายุประกัน และแสดง Badge สถานะ (✅ ยังอยู่ในประกัน, ⚠️ ใกล้หมดประกัน, ❌ หมดประกันแล้ว)
- [x] **Maintenance Logs (Planned):** บันทึกประวัติการส่งซ่อม ส่งเคลม และค่าใช้จ่าย
- [x] **Dashboard (Planned):** สรุปยอดค่าใช้จ่ายการซ่อมบำรุงแยกตามหมวดหมู่อุปกรณ์

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
*   **Frontend:** HTML5, CSS3, Bootstrap 5
*   **Backend:** PHP
*   **Database:** MySQL
*   **Server:** Deploy บนเซิร์ฟเวอร์ Angsila

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)
โปรเจกต์นี้ประกอบด้วยตารางหลัก ดังนี้:
1.  `Users` - เก็บข้อมูลผู้ใช้งาน
2.  `Assets` - เก็บข้อมูลอุปกรณ์ไอทีและวันหมดประกัน
3.  *(Planned)* `Categories`, `Vendors`, `Maintenance_Logs`

*ดูโครงสร้างตารางฉบับเต็มได้ในไฟล์ `database.sql`*

## 🚀 วิธีการติดตั้งและทดลองรัน (Installation)

1.  **Clone Repository:**
    ```bash
    git clone https://github.com/sharpnex42/Gadget-Warranty-Vault.git
    ```
2.  **ตั้งค่าฐานข้อมูล:**
    *   สร้างฐานข้อมูลใน MySQL
    *   นำเข้า (Import) โครงสร้างตารางจากไฟล์ `database.sql`
3.  **ตั้งค่าการเชื่อมต่อ (Database Connection):**
    *   แก้ไขไฟล์ `db_connect.php` หรือใช้ตัวอย่างจาก `db_connect_example.php` เพื่อตั้งค่า Host, Username, Password และ Database name ให้ตรงกับเซิร์ฟเวอร์ของคุณ
4.  **เริ่มต้นใช้งาน:**
    *   เปิดไฟล์ผ่าน Localhost หรือเซิร์ฟเวอร์ของคุณ
    *   ไปที่หน้า `register.php` เพื่อสร้างบัญชีแรกและเริ่มใช้งาน
